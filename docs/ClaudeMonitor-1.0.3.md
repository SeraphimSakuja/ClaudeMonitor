# ClaudeMonitor 1.0.3

Small update.

## Changed: usage colors now switch at 70 % and 90 %

The usage indicator is green below 70 %, yellow from 70 % to 90 % and red above 90 %
(previously 50 % and 85 %). ClaudeMonitor now shows the same colors as claude-swap.

## Requirements

macOS 14 or later, and a running `claude-swap` installation.
